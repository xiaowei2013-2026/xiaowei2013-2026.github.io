## 1. 糖尿病究竟是什么

**糖尿病的核心，是血液中的葡萄糖长期过高。** 胰岛素不足，或身体不能有效利用胰岛素，都可能造成这一结果。

先认识三个词：

| 名词       | 通俗理解                                       |
| ---------- | ---------------------------------------------- |
| 葡萄糖     | 身体的重要能量来源，血液中的葡萄糖就是“血糖”   |
| 胰岛素     | 胰腺分泌的激素，帮助葡萄糖进入细胞被利用       |
| 胰岛素抵抗 | 身体对胰岛素的反应变弱，相同作用需要更多胰岛素 |

吃进的碳水化合物经过消化，可以成为葡萄糖；胰岛素参与调节血糖。胰岛素不足或作用减弱时，血液里糖多，细胞却不一定能有效利用。糖尿病因此不能简单归因于“吃糖太多”，也不能用“尿里有没有糖”作为唯一判断。[NIDDK：糖尿病的症状与原因](https://www.niddk.nih.gov/health-information/diabetes/overview/symptoms-causes)

## 2. 先分清类型

| 类型         | 主要问题                                               | 需要记住什么                                     |
| ------------ | ------------------------------------------------------ | ------------------------------------------------ |
| 1 型糖尿病   | 通常是免疫系统损伤产生胰岛素的细胞，导致明显缺乏胰岛素 | 可以发生在不同年龄，通常需要胰岛素治疗           |
| 2 型糖尿病   | 胰岛素抵抗与胰岛素分泌不足共同作用                     | 生活方式、遗传等因素共同参与，体重正常也可能患病 |
| 妊娠糖尿病   | 妊娠期间出现的糖代谢异常                               | 检查标准和管理要求与普通成人不同，产后也需随访   |
| 其他特殊类型 | 某些遗传、胰腺疾病或药物等造成                         | 需要医生判断原因，不能都当成 2 型处理            |

**“年轻就是 1 型，年纪大就是 2 型”不可靠；“用了胰岛素就是 1 型”也不可靠。** 2 型患者也可能需要胰岛素。分型有时还需要结合自身抗体等检查。[NIDDK：糖尿病概述](https://www.niddk.nih.gov/health-information/diabetes/overview)、[检查与诊断](https://www.niddk.nih.gov/health-information/diabetes/overview/tests-diagnosis)

## 3. 为什么没有不舒服也要检查

可能出现口渴、尿多、疲倦、视物模糊或不明原因体重下降。但 2 型糖尿病可以发展缓慢，早期症状不明显，甚至没有症状。

长期高血糖可能损伤血管和神经，影响心脑血管、眼睛、肾脏和足部。因此，治疗不仅是让血糖数字下降，还包括预防这些问题；没有症状不代表没有风险。[世界卫生组织：糖尿病问答](https://www.who.int/news-room/questions-and-answers/item/diabetes)

## 4. 怎么看懂检查指标

### 常见检查各看什么

| 检查                       | 它回答的问题                                 |
| -------------------------- | -------------------------------------------- |
| 空腹血糖                   | 至少 8 小时未摄入热量后，血糖是多少          |
| 随机血糖                   | 不限定进餐时间的某一刻，血糖是多少           |
| 口服葡萄糖耐量试验（OGTT） | 按规定喝葡萄糖液后，身体处理葡萄糖的能力如何 |
| 糖化血红蛋白（HbA1c）      | 过去约 2～3 个月的平均血糖水平如何           |

HbA1c 像一段时间的平均成绩，不能反映每次波动。贫血、某些血红蛋白异常等也可能影响结果，需要医生解释。

### 诊断界值要和检测条件一起看

以下用于理解**非妊娠人群**的常见诊断界值，血糖指实验室静脉血浆葡萄糖：

| 检查                                   | 达到糖尿病诊断界值 |
| -------------------------------------- | ------------------ |
| 空腹血糖                               | ≥ 7.0 mmol/L       |
| OGTT 糖负荷后 2 小时血糖               | ≥ 11.1 mmol/L      |
| HbA1c（符合标准的实验室检测）          | ≥ 6.5%             |
| 随机血糖，伴典型高血糖症状或高血糖危象 | ≥ 11.1 mmol/L      |

通常需要复查或其他检测确认，尤其没有典型症状时。普通一餐后的血糖不是 OGTT；家用血糖仪的一次结果，也不能直接当作确诊依据。检测单位要看清：7.0 mmol/L 约等于 126 mg/dL。[NIDDK：检查与诊断](https://www.niddk.nih.gov/health-information/diabetes/overview/tests-diagnosis)

**诊断标准不等于治疗目标。** 前者用于识别疾病，后者由医生结合个人情况制定，不能拿诊断界值当成自己的日常目标。对于“糖尿病前期”，不同指南的界值也有差异，不能把不同资料的标准拼在一起使用。[NIDDK：管理糖尿病](https://www.niddk.nih.gov/health-information/diabetes/overview/managing-diabetes)

## 5. 日常管理为什么不只是少吃糖

### 饮食：同时看食物种类和份量

米饭、面条、馒头等含有淀粉，也会影响血糖；不吃甜食不等于不摄入碳水化合物。主食并非一律禁止，需要结合总量和个人情况安排。

初学者可以用“餐盘法”理解搭配：大约半盘非淀粉类蔬菜，四分之一蛋白质食物，四分之一含碳水化合物的食物。它是份量和搭配的入门工具，不是每个人固定不变的食谱。[NIDDK：健康生活与糖尿病](https://www.niddk.nih.gov/health-information/diabetes/overview/healthy-living-with-diabetes)

实际饮食尽量多样，适当选择全谷物、蔬菜、豆类及鱼、禽、蛋、瘦肉等；保持健康体重。水果可以纳入饮食安排，份量仍要考虑。不要把某种“降糖食品”或保健品当作药物替代品。[国家卫生健康委：食养指导说明](https://www.nhc.gov.cn/xcs/c100122/202312/f24e98fc0bc343efa6168b8d788549c1.shtml)、[NIDDK：健康生活与糖尿病](https://www.niddk.nih.gov/health-information/diabetes/overview/healthy-living-with-diabetes)

### 活动：规律、可持续，并考虑安全

多数成年人可朝每周至少 150 分钟中等强度活动努力，例如快走；从可承受的活动量开始。如果已有糖尿病并发症，或使用胰岛素等可能引起低血糖的药物，应先确认适合的活动方式和监测安排。临时少吃饭、突然增加运动，并不一定安全。[世界卫生组织：糖尿病](https://www.who.int/news-room/fact-sheets/detail/diabetes)、[NIDDK：健康生活与糖尿病](https://www.niddk.nih.gov/health-information/diabetes/overview/healthy-living-with-diabetes)

## 6. 药物和监测要理解到什么程度

胰岛素是身体本来就需要的激素。1 型患者通常需要补充胰岛素；2 型患者可能使用口服药、注射药或胰岛素。需要什么治疗，取决于病情和其他健康问题，并不是凭一次血糖结果决定。

学习药物时，先问清楚“为什么用、怎么用、可能有什么不良反应、什么时候联系医生”，不用急着背剂量。漏服后怎么处理、是否能停药，都要按个人医嘱执行。[NIDDK：胰岛素、药物与其他治疗](https://www.niddk.nih.gov/health-information/diabetes/overview/insulin-medicines-treatments)

日常指尖血糖和连续葡萄糖监测用于观察趋势，HbA1c 用于观察较长期的控制情况。还要管理血压、血脂，按计划筛查眼、肾、神经和足部问题。监测频率、检查项目和目标应由医疗团队制定。[NIDDK：管理糖尿病](https://www.niddk.nih.gov/health-information/diabetes/overview/managing-diabetes)、[预防并发症](https://www.niddk.nih.gov/health-information/diabetes/overview/preventing-problems)

## 7. 低血糖与急症：家属也要知道

使用胰岛素或部分降糖药时，可能发生低血糖。常见表现有出汗、手抖、心慌、饥饿、头晕或意识改变；有些人症状并不明显。对许多糖尿病患者，血糖低于 3.9 mmol/L 是需要及时处理的警戒值。

**人清醒、能够安全吞咽时**，低血糖通常按以下原则处理：

1. 尽快摄入约 15～20 克快速吸收的葡萄糖或碳水化合物，例如按包装标注量使用葡萄糖片。
2. 等待 15 分钟，再测血糖；仍低时重复处理。
3. 恢复后按既定计划安排饮食，并查明诱因。反复低血糖应联系医生调整方案。

部分减慢碳水化合物消化的药物会影响其他糖类的起效，发生低血糖时应优先使用葡萄糖，并遵循医生预先制定的方案。**如果昏迷、抽搐或不能安全吞咽，不要往嘴里喂水或食物，立即呼叫当地急救；已配备胰高血糖素且受过培训的人，可按既定急救方案使用。** [NIDDK：低血糖](https://www.niddk.nih.gov/health-information/diabetes/overview/preventing-problems/low-blood-glucose-hypoglycemia)

持续呕吐、腹痛、明显脱水、呼吸异常或意识改变，可能提示严重问题。糖尿病酮症酸中毒等属于急症，不应在家仅靠喝水、运动或自行加药处理。[NIDDK：症状与原因](https://www.niddk.nih.gov/health-information/diabetes/overview/symptoms-causes)

## 8. 常见误区

| 说法                             | 更准确的理解                                      |
| -------------------------------- | ------------------------------------------------- |
| 不吃甜食就不会得糖尿病           | 多种因素共同参与，其他碳水化合物也会影响血糖      |
| 没有“三多一少”就没事             | 2 型糖尿病可以长期没有明显症状                    |
| 胰岛素会让人上瘾                 | 它是补充或支持身体所需的激素，是否使用由病情决定  |
| 血糖越低越好                     | 需要兼顾控制目标与低血糖风险                      |
| 一次检查正常就能自行停药         | 单次结果不能代表长期情况，停药要由医生判断        |
| 有人“逆转”了，所以糖尿病都能治愈 | 部分 2 型患者可达到缓解，但可能复发，仍要持续管理 |

“缓解”与“治愈”不同，不意味着永久没有风险，也不适用于所有糖尿病类型。[NIDDK：2 型糖尿病缓解](https://www.niddk.nih.gov/health-information/professionals/diabetes-discoveries-practice/achieving-type-2-diabetes-remission-through-weight-loss)。其余误区可对照上文各节的原理和来源理解。

## 9. 非医学生的学习顺序

先学第 1～4 节，能用自己的话解释血糖、胰岛素、分型和检测条件；再学饮食、活动、药物和监测；最后学习并发症和急症识别。无需一次记住所有药名。

可以用以下问题检验自己是否理解：

- 为什么“不吃甜食”不等于血糖一定正常？
- 为什么没有症状仍可能需要检查？
- 空腹血糖、OGTT 和 HbA1c 分别回答什么问题？
- 为什么患者的治疗目标不能直接套用诊断标准？
- 为什么管理糖尿病还要关心血压、血脂、眼睛和肾脏？
- 低血糖患者清醒和昏迷时，处理有什么关键区别？

如果是为了帮助某位家人，可在就诊时先确认：糖尿病类型、个人控制目标、现用药物是否可能引起低血糖、在家测量的时间、复查与并发症筛查安排。不要仅凭网上的一张表给家人调整药物。
